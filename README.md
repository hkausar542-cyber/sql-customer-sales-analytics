# SQL Customer Sales Analytics (SQL + Power BI)

A SQL and Power BI project that analyzes customer sales, revenue by category, top customers and monthly revenue trends.

## Dashboard Preview
![Sales Performance & Customer Analytics](Screenshot%202026-11-12%20172255.png)

## Objective
Use SQL to prepare and analyze sales data, then visualize the results in Power BI to find top customers, best-selling categories and revenue trends.

## Tools Used
- SQL (joins, CTEs, window functions)
- Power BI
- CSV data files

## Key Metrics
- Total Revenue: 294.89K
- Electronics: 76.46% of revenue
- Furniture: 15.38% of revenue
- Accessories: 8.16% of revenue

## Key Insights
- Electronics brings in about three-quarters of total revenue
- Saad Malik is the top customer by revenue, ahead of Danish Iqbal and Faisal Iqbal
- Monthly revenue peaks around April 2024 and rises overall from 2023 to 2024

## Files
- `sales_analytics.sql` and `sql.sql`: SQL queries
- `customers.csv`, `orders.csv`, `order_items.csv`, `products.csv`: source data
- `monthly_trend.cvs.csv` and `top_customer.cvs.csv`: query results
- `sales_analytics_dashboard.pbix`: Power BI dashboard
- `Screenshot 2026-11-12 172255.png`: dashboard screenshot
